## Publish with GitHub Pages
1. Create a public repository at https://github.com/new (suggested name: `for-pragya`).
2. Upload the contents of this project folder (including the `assets` folder) to the repository root. Do not upload only the ZIP.
3. Go to Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch `main` and folder `/(root)`, then Save.
6. After publishing, GitHub will show the website URL, usually `https://YOUR-USERNAME.github.io/for-pragya/`.

GitHub Pages is public. Anyone with the URL can view your photographs and letter. Only publish what you are comfortable sharing.
